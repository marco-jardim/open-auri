# Phase 4 test battery (T4.T, integration part)

Plan: `docs/plans/2026-10-15-open-auri-web-plano.md`, T4.T (cases at lines ~2197–2212). Everything
runs in workerd (`npm run -w web test:int`, coverage with `test:int:coverage`). The D1 database, KV
and R2 are shared between files: every test uses unique ids and nicknames, never global counts,
and never flips shared switches (read-only mode is tested through a KV view, see below).

## Files of this folder

| File                        | What it covers                                                                                                                                                                                                                         |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `helpers.ts`                | Personas (`member()`), synthetic events for any `/api/v1` route and method, `invoke()` without casts, `errorCode`, `loadStatus` (SvelteKit `error`/`redirect`)                                                                         |
| `import-meta-glob.d.ts`     | Type of Vite's `import.meta.glob` (the integration tsconfig does not load `vite/client`)                                                                                                                                               |
| `authz-matrix.test.ts`      | anonymous × banned × unverified × verified × admin × owner for every `/api/v1` route file and method; self-check against the files (`import.meta.glob`); `/c/[id]`, `/u/[apelido]`, `/og/[id].png`                                     |
| `visibility.test.ts`        | Private lineage absent from feed, rankings, profile (API and page), curve search, OG, someone else's share, pack and export; unlisted by id only                                                                                       |
| `protections.test.ts`       | Read-only mode over every route (writes 503 `READ_ONLY`, reads pass); XSS strings verbatim as JSON data; URL-like text refused; nickname confusables; a kit quota (packs, 429 + `retry-after`)                                         |
| `coverage-services.test.ts` | Focused branches of curves, shares, library (merge race), packs, trades (pairing retry), social queries, rankings, gate cache re-gating, OG fonts/store/route/warm-up                                                                  |
| `../gate-parity.test.ts`    | Server `checkCurve` × browser `handleGateRequest` (commit → `gateForWrite`): same verdict and reason codes on > 500 curves (11 presets, Neutro, rejected shapes, ABS_RANGES/THRESHOLDS boundaries, seeded random), sequential, chunked |
