# open-auri web

Interface SvelteKit para o open-auri, publicada em Cloudflare Workers.
Desenvolvimento: na raiz, configure o .env e execute `npm run -w web dev`.
Build: `npm run build:web`; prévia: `npm run -w web preview`.
Testes: `npm run test:web:unit`, `npm run test:web:int` e `npm run test:web:e2e`.
