Comunidade

Cada canal é um curator; cada VCA é um pack. As curvas moram num repositório público no GitHub, e é ele o banco de dados: a busca roda no seu navegador. Não há contas, curtidas nem servidor. Para entrar na mesa, uma curva passa pelo gate v2 e chega por pull request.

    Publicar é ir ao ar

    Quatro passos, todos pelo GitHub. O open-auri não guarda nada: você gera o envelope aqui, abre um pull request no repositório público de curvas e a CI repete o gate v2 antes do merge. A lâmpada acende quando o envelope passa no gate.

    Fonte: curva no scope
    Licença desta curva
    1. 01

      Gerar o envelope S5

      JSON open-auri/preset@1 com números, receita, licença e o código S1. Roda o gate v2 aqui no navegador.

    2. 02

      Fork do repositório de curvas

      No GitHub, com a sua conta de lá. Endereço do repositório a definir; nenhum login acontece nesta página.

    3. 03

      Abrir pull request

      Um arquivo por curva em curves/<curator>/<nome>.json. O texto do pull request sai pronto no monitor abaixo.

    4. 04

      A CI valida com o gate e publica

      A CI repete o gate v2. Se passar, o merge atualiza o índice estático e a curva entra na mesa. Se recusar, nada entra.
